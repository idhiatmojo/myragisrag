# Folder Artikel Ilmiah PDF (`data/papers/`)

Masukkan seluruh file PDF jurnal referensi kelompok Anda ke dalam folder ini (`data/papers/`).

## Catatan:
1. Saat pertama kali dijalankan, jika folder ini masih kosong, script `main.py` otomatis membuat **5 contoh PDF artikel ilmiah** (dari Elsevier, IEEE, Springer, Taylor & Francis, dan SAGE) bertema **RAG untuk Edukasi & Kesehatan Remaja (Kecanduan Smartphone & Rokok/Vaping)** agar pipeline dapat langsung diuji.
2. **Untuk menggunakan PDF jurnal milik kelompok Anda sendiri:**
   - Hapus 5 file PDF contoh (`01_...pdf` s/d `05_...pdf`) di folder ini.
   - Copy-paste file PDF jurnal Anda ke dalam folder `data/papers/`.
   - Jalankan ulang perintah `python main.py`.
